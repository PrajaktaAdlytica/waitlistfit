16 October 2026

START HERE
Open WaitListFit-brand-guide.pdf. Use logos/logo-primary.svg as the default company logo and icons/favicon.svg for the browser icon.

SELECTED DIRECTION
Keep Direction 3's departure-board hero and Direction 4's mint-blue continuous background. Use Berth Schedule for the rest: time strips, aligned rows, hairlines, grotesque typography, monospaced IDs and explicit review evidence.

LOGO MASTER
The W uses two berth-shaped wells and a separated amber docking tile. This kit redraws the generated concept as clean vector geometry and standardizes the wordmark in Public Sans Bold. These SVGs supersede earlier draft logos and the placeholder logo visible in reference screenshots. SVG wordmark text is outlined. PNGs have transparent backgrounds. Reverse variants require a dark background.

FILES
logos/ — primary, reverse, ink monochrome and white monochrome horizontal logos and symbols; stacked logo. SVG and PNG.
icons/ — SVG favicon; ICO; PNG at 16, 32, 48, 180, 192, 512 px; five original module icons.
fonts/ — Public Sans static TTF weights 400, 500, 600, 700; variable WOFF2; OFL license. Source: https://github.com/uswds/public-sans . System monospace is specified, not redistributed.
tokens/ — JSON type/color/spacing/motion values and CSS variables. CSS is a handoff reference, not a built site.
applications/ — editable SVG and PNG social preview plus mint-blue background.
references/ — the selected hero/background and Berth Schedule reference images, not production screenshots. Logos in those reference images are earlier concepts.
checks/ — measured color contrast and delivery audit.
manifest.webmanifest — icon paths assume the kit structure; update deployment paths during implementation.

GUARDRAILS
Only concept previews and synthetic data. No PHI, live connections, automatic booking, outreach, diagnosis/treatment, compliance, efficacy or ROI claims. Approval shown in the demo is local simulation only. Sources and reviewer identity must remain visible. A still state must convey the full story with reduced motion enabled.

WHAT IS NOT INCLUDED
No website implementation/deployment, operational app, trademark clearance, live lead form or analytics. The original IA remains the content source; this kit controls brand presentation and does not replace the full brief.

REUSE
Original vector masters and native layout graphics created for this project. The two reference PNGs were generated earlier with ImageGen. Public Sans is supplied under the included SIL Open Font License. Keep the license with any redistributed font files.
